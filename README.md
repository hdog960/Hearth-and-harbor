# Hearth & Harbor v2.4.2 — Neighbor Postcards

An original, iPhone-first 2.5D life simulator hosted on GitHub Pages.

## New in v2.4.2
- Friendly villagers can send optional daily invitations after building a relationship with Poppy.
- An existing dating partner may initiate a romantic outing; nobody develops romance without the player's prior involvement.
- Open **People → Postcards** or **Hearts & Personalities → Postcards**. Accept, decline with no penalty, or resume an interrupted outing.
- Both characters must walk to the location before a friendship or romance reward is awarded.
- Friendly outings create friendship, improve social/fun needs, and generate a saved memory, **not** romantic progression.
- Invitations are one per in-game day; save validation keeps imported letter data safe. Old saves continue to work.

The cooking system (12 recipes), household controls, decorating and earlier Hearts & Personalities features are preserved.

## Still in development
Autonomous marriages, full romantic AI between NPCs, family generations, and the major v2.5 town expansion are not yet implemented. This is the first piece of resident-initiated social life.

## Running
Serve the repository root over HTTPS (GitHub Pages). Open with Safari on iPhone. Saves are kept locally in the browser. Export a backup from the in-game Menu before extensive testing.
