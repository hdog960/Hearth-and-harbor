# Hearth & Harbor v1.4 — Neighbors & Stories

A free, offline-save-capable, original 2.5D cozy life simulator for iPhone Safari and GitHub Pages. No account, subscription, ads, or backend required.

## New in 1.4

- Two scheduled **resident-to-resident community meetups per in-game day**, at 10:00–12:45 and 16:00–18:45, rotating across 12 authored pairings and stories. Residents take routes to the café, market, garden, library, square, or pond, rather than teleporting.
- During meetings, resident routines, in-world activity icons, and “How's your day?” reflect their actual activity.
- When both participants arrive, their **neighbor-to-neighbor bond** increases by 5 (up to 100), and a persistent entry appears in **Town Stories**. Each event can occur only once per in-game day/time slot.
- New **News** conversation choice, **Town Stories** journal, and a best-friend note in the People panel.
- Existing player relationships, gardening, fishing, decorating, navigation, and saved games are preserved. Older saves safely get default story and bond fields.

## Run and deploy

Place the files at a GitHub Pages repository root, publish from `main` / `(root)` and visit the published URL. The web app caches its shell and saves on the current device. Export backups using Menu.

## Honest scope

Meetups are generated by deterministic daily schedules and resolved only while the player is in the town with time running. This is not a true independent offscreen economy or persistent simulation after the browser is closed. Other villagers' houses aren't enterable yet.
